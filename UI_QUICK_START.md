## 🐛 **Troubleshooting**

**"Can't find file"**
- Make sure you ran `flutter pub get`
- Restart your IDE

**"Google Fonts error"**
- Internet connection required for first font download
- Fonts are cached after first load

**Build errors**
- Run `flutter clean`
- Run `flutter pub get`
- Try again
